# Roadmap

*Verejný prehľad uskutočnených a plánovaných zmien Songbook Managera.*

## Hotové

- vyhľadávanie a filtrovanie piesní,
- transponovanie akordov a Capo 0 pri renderovaní spevníka,
- história úprav piesní a lockovanie verzií spevníka,
- tagy a náročnosť v spevníku,
- pridávanie, odstraňovanie a presúvanie kategórií a piesní,
- export spevníka do PDF,
- používateľský profil a wishlist piesní.

## Práve pripravujeme

- import piesní z webu, textu a PDF,
- bezpečnejšie čítanie piesní, auto-scroll a zobrazovanie nástrojov v spevníku.

## Nasledujúce balíky

1. metadata a pôvod piesní (strumming, pôvodné/prevzaté akordy, interpret originálu a prekladateľ),
2. reportovanie chýb, zoznam spevníkov pri piesni a admin katalóg,
3. automatický obsah a vylepšenia PDF/tlače spevníkov,
4. XP ledger, leaderboard a dashboard,
5. skupiny, členovia a checklisty,
6. dark mode.

Každý balík bude samostatný pull request do `main`, aby sa dal otestovať a reviewovať bez zbytočných zásahov do legacy kódu.

## Vyžaduje rozhodnutie alebo externé nastavenie

- e-mailová verifikácia a obnova hesla — **Jatofi** (výber poskytovateľa a nastavenie domény),
- nový názov projektu a kompletný UI redesign,
- nové základné žánrové kategórie,
- správy a upozornenia,
- typy tagov, jednorázové spevníky a custom font,
- import playlistov z YouTube, Spotify a Apple Music,
- LLM poradie piesní a zjednocovanie canonical verzií piesní.
